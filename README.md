🎬 FlixZone – Movie Recommendation App

Discover movies, explore trailers, and enjoy a seamless movie-browsing experience with FlixZone.

📌 Overview

FlixZone is a modern movie application featuring a React frontend and a Node.js backend. It provides an engaging platform for exploring movies and enjoying a visually appealing movie experience.

✨ Features

- 🎞️ Movie browsing and discovery
- 🔍 Movie search functionality
- 🎬 Movie trailer viewing
- 👤 User management
- 📱 Interactive user interface
- 🎨 Modern and responsive design

🛠️ Technologies Used

Frontend

- React
- Material UI (MUI)
- JavaScript

Backend

- Node.js
- Express.js
- MongoDB

🚀 Installation & Setup

1. Clone the repository

git clone https://github.com/abzk-a/movie-app.git
cd movie-app

2. Install frontend dependencies

cd client
npm install

3. Install backend dependencies

Open another terminal:

cd server
npm install

4. Configure environment variables

Create a ".env" file inside the server directory and add the required configuration.

Never upload private credentials or API keys to GitHub.

5. Run the application

Check the scripts in each "package.json" to determine the correct commands to start the frontend and backend.
